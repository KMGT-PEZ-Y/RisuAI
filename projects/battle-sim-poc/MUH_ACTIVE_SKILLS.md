# M/U/H 액티브 스킬 30종

2026-09-04 Python POC 구현. 전부 **1레벨 플레이테스트 초안**이며 밸런스 확정값은 아니다.
데이터의 단일 기준은 `muh_skills.py`의 `MUH_SKILLS`이다. NG+ 평가/탐색 AI도 연결했으며 사용법과 계산량은 `NG_PLUS_AI.md`를 참조한다. Lua 포팅은 후속 작업이다.

## 실행과 사용

저장소 루트에서 `projects\battle-sim-poc\play_muh_skills.cmd`를 실행한다.

- Player와 Enemy 각각 목록에서 Ctrl/Shift로 최대 5개 장착 후 `선택한 장착으로 새 경기`.
- Enemy AI에 NG+를 선택하면 `NG+ 자동`으로 동작하며, 자유 장착한 덱의 행동과 스킬을 함께 판단한다. 판단 충실도 0~1과 판단 로그를 제공한다.
- 기존 Enemy AI 모드: `수동 입력`, `무작위 스킬`, `무스킬`. 모드와 장착 변경은 새 경기에서 적용된다.
- 수동 모드는 양측 행동·스킬을 지정한다. 양측 입력을 먼저 검증한 뒤 한 턴 진행한다.
- 무작위 모드는 기존 기본 행동 AI에 합법 스킬/미사용 균등 선택을 붙인 시험용이다. NG+ AI가 아니다.
- 다운/그로기도 버튼 한 번에 한 턴만 진행한다. Enemy만 행동 가능한 턴도 Enemy 수동 입력으로 시험 가능하다.
- 스킬 상세에 효과·조건·STA·CD·횟수, 양측 표에 실제 비용·남은 CD·횟수를 표시한다.
- 상태 패널에서 준비·디버프·후딜의 이름, 제거 가능 여부와 만료를 확인한다. 실제 비용은 Raw trace의 `skill_cost`에 기록된다.
- 기존 C-D UI와 쉬움 적 UI는 별도로 유지한다.

## 공통 계약과 명세 정리

1. 한 턴에 기본 행동 하나 + 스킬 최대 하나. M/U/H를 포함한 세트는 최대 5개, 제어(M09/U08/H08)와 결정기(H06/H09/H10)는 각각 최대 하나다. H08+H09는 함께 장착할 수 없다. 양측과 직접 엔진 생성 모두 동일하다.
2. CD N은 시전 턴을 제외하고 이후 자기 턴 N개 동안 사용 불가다. 다운 대기 중에도 감소한다. 경기당 사용 횟수는 인터벌이나 횟수 증가 효과로 재충전되지 않는다.
3. 비용·쿨다운·시작 조건은 양측 사전 검증한다. 불법 입력은 비용/횟수를 소비하지 않는다. 시전 후 주사위·효과 조건 실패는 비용/횟수를 반환하지 않는다.
4. 추가 HP 피해/BRK 증가와 배율은 기본 결과표에서 해당 방향 변화가 발생한 경우에만 적용한다. 빗나간 공격에 피해를 만들지 않는다. 소수점은 기존 부호 있는 값의 내림 규칙이다.
5. 다음 턴 효과는 다음 자기 턴 하나이며 행동하지 못해도 만료한다. M/U/H에는 기존 C-D 상태의 인터벌 추가 2턴 차감을 적용하지 않는다. 라운드 마지막 턴의 준비는 다음 라운드 첫 턴에 사용할 수 있다.
6. 피해 준비는 `damage_preparation`, 할인 준비는 `cost_preparation` 그룹에 각각 하나만 존재한다. 같은 그룹의 새 준비가 이전 것을 교체한다. 피해 준비는 다음 공격에서 소비되며 공격하지 않아도 해당 턴 종료 시 만료한다.
7. 할인은 `attack_boost` 태그의 공격 강화 스킬에만 적용하며 최소 지불액은 8 STA다. 준비·회복·제어에는 적용되지 않는다. U04의 CD 감소는 결정기/제어에 적용되지 않고 일반 스킬도 최소 CD 2를 유지한다.
8. H04→H05는 할인 없이 H05 비용을 지불하고 H04 할인의 만료만 한 턴 연장한다. 연장은 한 번만 가능하다. M04→M05 할인은 앞선 제안의 모순을 정정하여 지원하지 않는다.
9. M07/U07/H07은 시작 시 상대에게 `preparation` 태그 상태가 있어야 선택한다. 결과 처리 후 가장 최근 준비 하나를 제거한다. 이미 이번 턴에 발동/소비한 효과는 소급 취소하지 않는다. 준비가 먼저 사라져도 U07/H07의 STA 감소는 독립 적용된다.
10. 정화는 가장 오래된 제거 가능 디버프 하나다. 자기 기술의 후딜은 제거 불가능하다. H06 후딜은 기본 행동을 허용하고 모든 액티브 스킬을 금지한다.
11. U08/H02 행동 금지는 입력 검증 단계부터 적용한다. H08 강제 공격과 행동 금지가 겹치면 강제 공격을 우선한다. 자동 기본 행동 AI도 같은 합법 행동 집합을 따른다.
12. 결과 후 직접 회복은 HP 0인 캐릭터를 되살리지 않는다. H10은 HP를 먼저 감소시키고 살아 있는 경우에만 BRK를 추가한다. 다운/KO는 기존 턴 종료 판정에서 한 번만 처리한다.

M09→H09는 기존 장착 제한상 합법이며 실제 고가치 여부는 후속 밸런스 검증 대상이다.

## 구현 인터페이스

- `muh_skills.py`: 30종 선언, 레지스트리 로드, 장착 제한.
- `skill_schema.py`: 상태 태그/그룹/활성 조건·시점/효과 대상/소비/인터벌 감소, `status_tag_present`, `cost_discount`, `seal`.
- `battle_sim.py`: 공통 timing 실행기와 `legal_actions()` 입력 제한. 할인은 비용 지불 전에 조회·소비.
- `muh_testbed.py`: 양측 독립 장착·수동 입력의 원자적 검증, 기존 랜덤 정책 연결.
- `muh_playtest_ui.py`: 기존 UI를 재사용한 별도 화면.

## 검증

- 전체 자동 테스트 149개 통과(기존 106 + M/U/H 27 + NG+ 16).
- 30종 모두 Player/Enemy에서 조건 충족 후 시전·효과 실행 확인.
- 공격 강화의 행동 조합·주사위 승/무/패, 준비 소비·교체·제거, 할인 하한·연장·만료, 다음 턴 제어·후딜 검증.
- M05→M06 피해 +16, U05→U06 +17/최소 4, H04→H05→H06 +22/할인 검증.
- 여러 컨셉 장착을 조합한 36개 시드 대전 종료 확인. 승률/난이도 밸런스 검증은 아니다.
- 실제 Tkinter 숨김 창에서 30종 목록, 양측 5개 장착, 10개 런타임 행, 첫 턴 실행 확인.
