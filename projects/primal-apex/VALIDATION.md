# Primal Apex 0.1.0 검증

검증일: 2026-09-08. 산출물은 `release`의 독립 `.risum` 네 개다.

## 검증 범위의 한계

- 설치된 RisuAI.exe에 파일을 가져오는 작업이나 사용자의 실제 채팅 변경은 하지 않았다. 공식 실행기 계약과 같은 Lua/WASM 계열 및 별도 브라우저에서 검증했다.
- LLM 응답은 테스트 응답으로 대체했다. 실제 사용자 모델 호출, 모델별 패킷 준수율, 실제 서사의 품질은 검증하지 않았다.
- 브라우저 레이아웃 검사에서 전투 이미지 경로는 테스트용 실루엣으로 대체했다. 실루엣은 배포 에셋이 아니다. 실제 선수 사진은 원본 참조 카드에도 포함되지 않아 이번 배포본에 넣지 않았다.
- 고정 컵은 정해진 세 상대와 싸우는 시나리오다. 탈락식 브래킷 전체를 시뮬레이션하지 않는다.
- 신규 기능의 성장 비용, 관계·보상 수치와 시간 비용은 프로토타입 기본값이다. 밸런스와 장기 플레이는 후속 검증 대상이다.

재현 명령과 의존성은 `README.md`를 참고한다. 상세 결과와 스크린샷은 로컬 `qa` 폴더에 생성된다.
