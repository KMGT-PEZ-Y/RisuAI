# 검증 결과

검증일: 2026-09-08. 기계 판독 결과는 `qa/results.json`, 배포 파일 해시는 `release/manifest.json`에 있다.

## 통과한 항목

- Python 표준 라이브러리로 `.risum`과 `.charx` 생성, 모듈 역변환 후 원본 Lua·CSS·메타데이터 동일성 검사, ZIP 무결성 검사.
- Wasmoon / Lua 5.4에서 실제 배포 Lua 실행. RisuAI의 JSON 구현 및 비동기 버튼 계약 사용.
- 거리, 슬립 대 직선·훅, 바디 대 가드, 잽 연결, 페인트 관통·만료, 클린치, 호흡 부족, 로프 제한, 동시 KO, 다운 중단, TKO, 코너 중복 처리, 판정, 훈련 상한 검사.
- 13 × 13 행동 조합을 4개 거리와 3개 로프 상태에서 좌우를 뒤집어 실행하여 피해·호흡·거리·로프의 대칭성 검사.
- 무작위 행동으로 **300경기** 완료. 체력·호흡·충격·로프·다운이 허용 범위를 유지하고 모든 경기가 제한 안에 종료됨.
- 위 규칙·무작위 검사에서 **107,594개 assertion** 통과. 무작위 정책 결과는 플레이어 승 20 / 패 251 / 무 29. 이는 게임 승률 추정이 아니라 엣지 케이스를 탐색하는 비전략적 정책 결과임.
- 아웃복서 스타일로 5개 라이벌 전부를 실제 상태 전이와 호스트 버튼을 통해 격파, 훈련 보상·진행·최종 챔피언 화면 확인. 테스트 계획기는 13³개의 후보를 평가하므로 인간 플레이 난도를 대표하지 않음.
- JSON 저장 후 Lua 엔진을 새로 생성해 리플레이 복구. 과거 화면·더블 클릭 무효화, 초기화 취소, 정확한 명령의 모델 전송 중단, 일반 대화 유지.
- Markdown → DOMPurify → RisuAI 클래스 접두사 처리를 거쳐 **10개 화면 × 1100·390·320px = 30개 레이아웃** 검사. 가로 넘침·유효 버튼 누락 없음.
- 실제 브라우저 DOM 클릭 → Lua 버튼 함수 → JSON 저장 → 화면 갱신으로 새 커리어에서 첫 교환까지 완료.
- 데스크톱 계획 화면과 모바일 시작 화면을 이미지로 직접 확인. PNG 20개와 정적 HTML 10개를 `qa`에 보관.

## 검증의 경계

**설치된 RisuAI 데스크톱 앱의 가져오기 창을 직접 조작한 검증은 수행하지 않았다.** 공식 소스의 모듈 형식·API 계약, 동일 계열 Lua 런타임, 브라우저의 정화·렌더링·클릭 흐름을 확인했다. 오래된 RisuAI 버전이나 다른 트리거 모듈과 함께 사용하는 환경에서 호스트 자체의 차이가 있을 수 있다.

HTML 미리보기는 정적 산출물이다. 실제 게임 플레이와 저장은 RisuAI 모듈 또는 동봉 CHARX에서 사용한다.
