# RisuAI Workspace

RisuAI 관련 실행 파일, 실험 프로젝트, 플러그인, 캐릭터 카드, 펫 자산과 구현 문서를 한곳에서 관리하는 작업 저장소입니다.

## 디렉터리 구조

- `apps/`: 실행 가능한 애플리케이션과 보조 서버
- `projects/`: 독립적으로 실행·검증할 수 있는 POC 및 Lua 프로젝트
- `plugins/`: RisuAI 플러그인 소스와 배포 자료
- `characters/`: RisuAI 캐릭터 카드(`.charx`)
- `assets/`: 펫 스프라이트, 미리보기와 패키지 자산
- `docs/`: 구현 명세와 코드 요약 문서
- `archives/`: 원본 ZIP 보관본
- `qa/`: 문서 및 산출물 검증 결과
- `tools/`: 저장소 공용 생성·검증 도구

각 프로젝트의 실행법은 해당 디렉터리의 `README.md`를 확인하세요.
