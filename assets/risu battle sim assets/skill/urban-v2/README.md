# Battle-sim — Modern Urban v2

기본 5종과 일반 등급 앞 5종을 기존 이미지에서 편집한 1024 × 1024 PNG 세트입니다. 내장 image_gen으로 각 원본을 참조해 수정했습니다. 최종 크기는 리샘플링하여 맞춥니다. 전체 프롬프트와 원본 경로는 prompts.json에 기록했습니다.

## 점검 및 수정

기존 세트의 거친 금속 표면, 판금 보호구와 금속 테두리는 중세 판타지 인상을 만들었습니다. 이번 수정은 매끈한 면, 정돈된 윤곽, 셀 음영과 현대 스포츠 소품으로 표현을 통일합니다. 어두운 배경과 기존 색상, 동작의 의미는 유지합니다.

|등급|스킬|색상|현대적 표현|
|---|---|---|---|
|기본|힘주어 치기|빨강|핸드랩을 감은 주먹|
|기본|자세 정비|파랑|트레이닝복과 회복 곡선|
|기본|안전한 발놀림|초록|운동화와 사이드스텝 궤적|
|기본|거리 확보|초록|운동복 차림 인물과 간격 화살표|
|기본|턱 당기기|주황|스포츠 셔츠와 트레이닝 장갑|
|일반|묵직한 한 방|빨강|패딩 복싱 글러브의 타격|
|일반|단단한 가드|파랑|현대 보호 패널과 교차한 스포츠 글러브|
|일반|호흡 정리|파랑|스포츠 건강 그래픽 형태의 폐와 호흡 곡선|
|일반|발판 잡기|노랑|바닥에 디딘 트레이닝화와 전진 화살표|
|일반|힘 모으기|주황|핸드랩을 감은 두 손과 집중의 동심원|

기본 등급은 단일 테두리선, 일반 등급은 이중선과 작은 기하학 표식을 사용합니다. 같은 계열의 모서리 모티브를 유지합니다. 발판 잡기의 공격/회피 노랑, 힘 모으기와 턱 당기기의 공격/방어 주황 등 기존 색상 해석을 유지합니다.

파일명은 skill_<기존 스킬 ID>.png이며, 기존 basic-v1 및 normal-v1 파일은 비교를 위해 보존합니다.
